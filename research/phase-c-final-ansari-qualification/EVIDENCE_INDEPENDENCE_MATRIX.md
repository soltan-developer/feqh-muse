# Evidence Independence Matrix — ممیزی استقلال شواهد

> اصل: دو صفحه/رکورد = دو دلیل نیست. تا احراز استقلال، وضعیت `INDEPENDENCE_UNVERIFIED` است.

| گروه | اعضا | حکم استقلال |
|---|---|---|
| G-KHATIMA | P-01..P-19 (خاتمهٔ فرائد ج۲، ص۳۵۱–۳۹۲) | یک رسالهٔ پیوسته از یک مؤلف: مواضع متعدد آن برای یک گزارهٔ واحد، «دو شاهد مستقل» شمرده نمی‌شوند؛ واحد شمارش = واحد استدلال، نه صفحه |
| G-V1-ZAWAHIR | NP-08، NP-11 (فرائد ج۱) | اثر/مقام متفاوت از خاتمه؛ استقلال **نسبی** (همان مؤلف، بافت استدلالی دیگر) — برای تقویت B-CANDIDATEها قابل قبول، با ذکر روش احراز: تفاوت اثر + تفاوت مقام بحث + عدم نقل یکی از دیگری |
| G-V1-IHTIYAT | P-21، P-22 (فرائد ج۱) | همان حکم G-V1-ZAWAHIR، اما نقل‌ها فعلاً NOT_VERIFIED رشته‌ای‌اند |
| G-USUL-CONFLICT | NP-01..NP-07 (فرائد ج۲، ص۳۳۵–۳۵۰) | یک مقام پیوسته (باب استصحاب)؛ برای AT-B هر NP واحد استدلالی جداست (تقسیم‌بندی خود متن) ولی همه از یک رساله‌اند |
| G-MAKASEB-DEV | P-23 و رخدادهای عذره | `previously_exposed_development_evidence` — هرگز شاهد مستقل قدرت انتقال نیست |
| G-COMMENTARY | 11756، 11723 | لایهٔ ۳ (شارح)؛ شاهد موضع شیخ نیستند |

## پیامد برای درجه‌های پیشنهادی
- A-CANDIDATEهای C1 (UNITY, JAM-NO-UNIVERSAL, DALALA-FIRST, TAKHYIR-LAST) عمدتاً درون G-KHATIMA + مؤیدهای G-V1 ایستاده‌اند؛ استقلال درون‌گروهی آنها «واحدهای استدلال متعدد در یک رساله» است — این در پرونده‌ها صریح شده تا داور انسانی بداند «استقلال» این‌جا دقیقاً چه معنایی دارد و چه معنایی ندارد.
- JAM-QARINA و TARJIH-OPEN به همین دلیل B می‌مانند: شاهد دومِ واقعاً مستقل (اثر/مقام دیگر با سهم استدلالی جدا) برای هستهٔ ادعایشان هنوز کامل نیست.
