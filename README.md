# feqh-muse — موتور اجتهاد شیخ انصاری

بازسازی قابل ممیزیِ الگوریتم اجتهادی شیخ انصاری از روی آثار خودش (فرائد الأصول و مکاسب)، با آزمون‌های کور پیش‌ثبت‌شده و موتور قواعد قابل نقض. وضعیت ادعا طبق قرارداد علمی پروژه: «موتور آزمایشیِ بازسازی استدلال» — ادعای کشف کامل الگوریتم هنوز مطرح نیست.

## نقشهٔ مخزن
- `docs/` — اسناد: استخراج الگوریتم (۲۹ قاعده)، ابرسند معماری شناختی (سند حاکم)، قرارداد علمی v3، سند چشم‌انداز و مشخصات v2، گزارش تکمیل v1، تست طلایی بیع عذره، فهرست کتاب‌های پروژه، جمع‌بندی مرحله.
- `engine-v1/` — موتور خط لولهٔ قواعد (L0–L3) + خروجی سه‌حالته + CLI و تست رگرسیون ۱۲ کیس.
- `engine2/` — موتور قواعد قابل نقض با دو دروازهٔ ورود (رتبهٔ علمی + شش فیلد صلاحیت اجرایی) و اجرای ماشینی کاوشگر ۱ (بازسازی مشروط مبنا).
- `blind-test-1/` — آزمون کور اول روی قواعد (۲۰ بخش تصادفی مکاسب؛ پیش‌بینی مهروموم؛ توافق ۸۸٪).
- `blind-test-2/` — آزمون کور دوم روی خود موتور (۱۲ بخش تازه؛ ۷/۸ توافق کامل، صفر اختلاف).
- `ghabn-case/` — پروندهٔ خیار غبن + لا ضرر: دو کدگذاری مستقل رخدادهای استدلال، نسخهٔ داوری‌شدهٔ نهایی، و متن‌های منبع (مکاسب ج۵ ص۱۵۷–۲۱۶؛ رسالهٔ لا ضرر).

## اجرای تست‌ها
```
python3 engine-v1/run_all_tests.py   # مجموعهٔ یکجا: رگرسیون v1 + کاوشگر موتور دوم + ایندکس
python3 engine2/run_probe1.py        # دروازه‌ها و ۵ سناریوی کاوشگر ۱
```

## آنچه اینجا نیست
پیکرهٔ کتاب‌ها (۳۰۰ فایل SQLite، ~۲٫۷ GB) و ایندکس شواهد (۶۶۵ MB) به‌علت حجم در این مخزن نیستند؛ فایل‌های فشردهٔ کتاب‌ها در مخزن `book-for-muse` هستند و ایندکس با `engine-v1/build_index_full.py` بازسازی می‌شود.
