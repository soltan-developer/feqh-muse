# نقشهٔ پوشش قواعد قفل‌شده برای بیع عذره + کلید داوری موقت

## الف) پوشش موتور قفل‌شده (نسخهٔ مانیفست پیوست)
موتور قفل‌شده سه دامنه دارد: هستهٔ غبن (خیار، بذل، تصرف)، صلحِ اطلاق (استخراج‌گر فارسی)، فور (اعذار چهارگانه)، و ماژول حدوث/اسقاط. هیچ‌یک از سازوکارهای این مسئله در آنها نیست:

| سازوکار مسئله | شناسهٔ خارج از پوشش | توضیح |
|---|---|---|
| تعارض دو خبر خاص و درمان آن | OOD-UDH-01 | موتور هیچ ماژول تعادل/تراجیح ندارد |
| جمع دلالی به تخصیص متقابل (نص/ظاهر) | OOD-UDH-02 | قاعدهٔ جمع در قواعد قفل‌شده نیست |
| قرینهٔ وحدت کلام (تنزّل نوع تعارض) | OOD-UDH-03 | تشخیص نوع تعارض پیاده‌سازی نشده |
| جبر ضعف سند با اجماع منقول | OOD-UDH-04 | ماشین سند/جبر وجود ندارد |
| ظهور لفظی و انصراف («العذرة») | OOD-UDH-05 | انصراف عربیِ کتابی خارج از الگوهای استخراج‌گر فارسی صلح است |
| گرهٔ دلیلِ نامذکور («وجوه لا تخفى») | OOD-UDH-06 | الگوی توقفش آشناست ولی قاعده‌ای برایش نیست |
| فرع ارواث و تبعیت حرمت ثمن از حرمت منفعت مقصوده | OOD-UDH-07 | قاعدهٔ عام بخش در موتور نیست |

**نتیجهٔ پوشش: ۰ از ۱۲ رخداد با قواعد قفل‌شده قابل اجراست.** رفتار صحیح موتور برای هر پروندهٔ این پایلوت در وضع فعلی `STOP-OUT-OF-DOMAIN` است. این دقیقاً همان چیزی است که پروتکل پایلوت برای مرحلهٔ گردآوری پیش‌بینی می‌کند؛ هیچ قاعده‌ای برای تغییر این وضعیت ساخته نشد.

## ب) کلید داوری موقت (مهروموم محتوایی با هش)
این بخش، **کدگذاری همین عامل** از مواضع شیخ در هر رخداد است — برای اینکه داور انسانی مستقل بتواند آن را راستی‌آزمایی، اصلاح و مبنای طراحی آزمون کور کند. این کلید **مستقل نیست** (نویسنده‌اش سازندهٔ موتور است) و تا وقتی داور انسانی آن را تأیید یا جایگزین نکرده، نباید مبنای نمره‌دهی کور قرار گیرد. هش SHA-256 متن این فایل در گزارش آمادگی پایلوت ثبت می‌شود تا هر تغییر بعدی آشکار باشد.

| رخداد | موضع شیخ (کدگذاری موقت) | سطح انتساب |
|---|---|---|
| U1 | حرمت = قول مشهور/اجماع منقول (طرح، نه رأی) | صریح شیخ / نقل |
| U2 | تعارض دو خبر برقرار | صریح |
| U3 | جمع طوسی | نقل (نه رأی شیخ) |
| U4 | مبنای نص/ظاهر برای جمع | بازسازی با «لعلّ» |
| U5 | تعارض دلالی است؛ مرجحات سندی/خارجی کنار | استظهار معتبر شیخ |
| U6 | اشکال مرجحات دفع شد | صریح |
| U7 | کراهه/بلاد/تقیه ردّ (دو مرتبهٔ بُعد) | صریح |
| U8 | جمع «الأظهر» مشروط؛ روایت جواز در فرض عدم جمع غیرقابل اخذ با وجوه نامذکور | استظهار مشروط + توقف مصرّح |
| U9 | تعمیم به غیر انسان مشروط به فرض انصراف | فرض (نه ترجیح) |
| U10 | اشکال «حسن» ولی اجماع منقول جابر است | صریح |
| U11 | استظهار از استبصار ناتمام: «فیه نظر» | اشکال/باز |
| U12 | ارواث طاهره: «الأقوى» جواز + ردّ دو مستند مخالف | ترجیح اقوى |
